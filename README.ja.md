# StickyTodo

[简体中文](README.md) | [English](README.en.md) | **日本語** | [한국어](README.ko.md)

ゼロから書き起こした Windows デスクトップ付箋 / ToDo アプリ：WPF + .NET 8 + SQLite。**すべてローカルで動作**——サーバー接続なし、アカウントなし、計測なし、更新確認なし。**全ユーザーが既定で永久メンバー、全機能無制限**。UI は**简体中文 / English / 日本語 / 한국어**の 4 言語に対応し、設定からいつでも切り替えられます。

> 同種ツールの製品形態（複数ボード、1 ボード 1 ウィンドウ、繰り返しタスク、カレンダー）は参考にしていますが、**コード・UI・文言・配色はすべて本プロジェクトのオリジナル実装**です。他社プログラムの逆コンパイル成果物、リソースファイル、非公開 API は一切コピーしていません。

## 0. ダウンロードしてすぐ使う（ポータブル版）

.NET ランタイムを入れたくない場合はポータブル版をどうぞ：

**[⬇ 最新の StickyTodo-x.x.x-win-x64-portable.zip をダウンロード](https://github.com/xiefengdaxia/StickyTodo-WPF/releases/latest)**

解凍して `StickyTodo.exe` をダブルクリックするだけ。**70 MB の単一 exe に .NET 8 ランタイムを同梱、依存なし**。

- アーカイブに `portable.marker` が入っているため、データ（`sticky.db` とログ）は exe 隣の `data\` に保存されます —— **フォルダごとコピーすればデータも一緒に移動**でき、USB メモリに最適
- `portable.marker` を削除すれば通常モード（`%LOCALAPPDATA%\StickyTodo`）に戻ります
- 初回起動時に SmartScreen の警告が出る場合があります（未署名）。「詳細情報」→「実行」を選んでください
- システム要件は下記「動作環境」を参照

**動作環境**

| 項目 | 要件 |
|---|---|
| OS | **Windows 10 1809（x64）以降**、Windows 11 の全バージョン |
| CPU | **x64**（ARM64 機は x64 エミュレーションで動作する可能性がありますが未検証） |
| .NET ランタイム | **不要**（.NET 8 を同梱） |
| その他の依存 | **なし**。WPF グラフィックスタック、SQLite ネイティブライブラリ、VC++ ランタイムをすべて同梱 |
| ディスク | 約 71 MB（exe 本体）。データは数 MB から |
| 権限 | 一般ユーザーで可。**管理者権限は不要**（自動起動は HKCU のみ書き込み） |

非対応：Windows 7/8/8.1（.NET 8 と WPF の新しい DPI API が非対応）、32 ビット環境、Linux/macOS。

**一時フォルダについて**：単一ファイル版は初回起動時にネイティブライブラリ（wpfgfx_cor3.dll、e_sqlite3.dll など計約 10 MB）を %TEMP%\.net\StickyTodo\ に展開します。%TEMP% が書き込み可能である必要があり、非常に厳しい一時フォルダポリシーの環境では起動できません。展開を避けたい場合は PublishSingleFile を外したフォルダ形式の自己完結発行にしてください。

自分でビルドする場合：

```powershell
.\tools\publish-portable.ps1 -Version 1.0.0                    # パッケージのみ
.\tools\publish-portable.ps1 -Version 1.0.0 -CreateRelease     # パッケージして GitHub Release へ公開
```

スクリプトは テスト → 単一ファイル発行 → ポータブルマーカー配置 → ZIP 作成 → **スモークテスト**（`--portable-check` で実プロセスを起動し、データが exe 隣に作られることを確認）→ 必要なら Release へアップロード、を順に実行します。

## 3. 現在の機能

**多言語（4 言語）**
- UI は**简体中文 / English / 日本語 / 한국어**に対応。設定画面の「言語」ドロップダウンで切り替え、**再起動なしで即時反映**
- 切り替え時は開いているすべてのウィンドウを走査し、コンバーターを使うバインディングを再評価します（`LocalizationService.RefreshAllWindows`）。そのため直後に全文言が変わります
- 選択した言語は保存され（`appearance.language`）、次回起動時に復元。適用は**ウィンドウを 1 枚も作る前**なので、一瞬中国語が見えることはありません
- `--lang en|ja|ko|zh-CN` でその起動だけ言語を強制できます（撮影回帰用、設定には保存されません）
- **旧暦の用語は中国語のまま**：旧暦の日付、干支、建除十二神、二十四節気の名前、吉凶の項目自体は翻訳しません（中国暦固有の概念で、無理に訳すと意味が通じないため）。「旧暦」「節気」「宜」「忌」といった**ラベル**だけが UI 言語に追従します
- 数値の単位も言語に追従：中国語は「万／億」、それ以外は `M/B`
- 文言の一貫性は単体テストで担保：`LocalizationTests` が 4 言語の揃い、`{0}/{1}` プレースホルダーの言語間一致、全訳文が `string.Format` を通ることを検証します

**外観（付箋らしさ）**
- **すべてのウィンドウにシステムタイトルバーがありません**：メイン画面、設定画面、付箋、入力ダイアログはすべて自前描画のタイトルバー（ドラッグ可、メインと設定は端リサイズと最大化にも対応）
- 付箋ウィンドウは**枠なし＋角丸＋ドロップシャドウ**、端 8px でリサイズ（`WM_NCHITTEST` を自前処理）
- **10 テーマ**：クラシックイエロー / ペーパーホワイト / ミント / スカイブルー / バイオレット / サクラピンク / アプリコット / グラファイト夜 / ミッドナイトインク / エスプレッソ（ダーク 3 種は文字が自動で明るくなります）
- **2 種類の不透明度を個別に調整、10% 刻みで 10 段階**：背景の不透明度 10〜100%（紙だけが透け、文字は常に鮮明）、ウィンドウの不透明度 10〜100%（文字も薄くなる）
- **透過するのは付箋・メモボード・カレンダーのみ**。メイン画面と設定画面は不透明ウィンドウです
- 自前描画コントロール：角丸チェックボックス、細いスライダー、フラットスクロールバー、セグメント切り替え、カード、**右クリックメニュー**（サブメニュー矢印、チェックマーク、区切り線、配色はテーマ追従）
- タイトルバーのボタン：📌 最前面固定、🔒 ロック、🎨 テーマ切り替え、⋯ メイン画面、✕ 閉じる
- 付箋はタスクバーに場所を取りません（付箋スタイル）。入口はトレイとメイン画面です

**設定画面（独立ウィンドウ）**
- **言語ドロップダウン**：4 言語を母語名で表示、選択で即時反映
- 10 テーマを**カラーカードのグリッド**で表示（2 行×5 個）。クリックで全ウィンドウに即時反映（再起動不要）
- 不透明度スライダー 2 本、リアルタイムプレビューと即時保存
- グローバルホットキー 3 つの一覧
- データ領域：メンバーシップ状態、コンテンツ統計（ボード／ToDo／完了／タグ数）、ローカル保存先
- 入口：メイン画面左下の「設定」、トレイ右クリックメニューの「設定」

**ボード**
- 1 ボードにつき 1 ウィンドウ、複数同時に開けます。開いているボードを再度開こうとすると既存ウィンドウがアクティブになります
- **4 種類のボード**：ToDo ボード（リスト）、メモボード（紙 1 枚、書きながら自動保存）、カレンダーボード（月表示）、Token 使用量ボード
- ウィンドウの位置とサイズはボードごとに記憶（再起動で元の位置へ）。モニター変更時は画面内に収まるよう補正
- **端吸着**：画面端や近くの付箋ウィンドウに自動で整列（紙の端で合わせ、影の余白は除外）
- 管理パネル：ToDo／メモ／カレンダーボードの作成、名前変更、削除、ダブルクリックで開く、種類と ToDo 件数を表示
- **カードの右クリックメニュー**：開く／名前を変更…／削除（右クリックしたカードが自動的に選択されます）
- **ウィンドウ全体をドラッグ可能**（ボタン、リスト項目、入力欄、スクロールバーを除く）。非インタラクティブ領域のダブルクリックで最大化／元に戻す
- トレイアイコン：各ボードウィンドウのチェック式表示切り替え、すべて表示／非表示、管理パネルを開く、終了。✕ はトレイに格納するだけ

**カレンダーボード**
- 月表示は 6 週固定グリッド（月曜始まり）。今日を強調、週末は赤字、月外の日付は淡色。曜日ヘッダーは言語に追従
- **各セルに旧暦を表示**（1 日は「X月」、それ以外は「初二／廿三」など）
- **二十四節気／伝統的な節句／法定休日**をセルに表示：節気（立春、清明、霜降…）、除夕、春節、元宵、端午、七夕、中秋、重陽、臘八、さらに元旦、労働節、国慶節など
- **「休」「班」バッジ**：赤い「休」は休み、グレーの「班」は振替出勤日（データは国務院の 2024〜2026 年の休日通知を手入力、通信なし）
- 予定のあるセルは色付きドットとタイトル概要を表示。下に選択日の予定一覧
- **日付をクリックすると吉凶を表示**：旧暦の日付、干支の年／生肖、日干支、建除十二神、そして**宜／忌**が各 5 項目
- **年月ドロップダウン**：任意の年（前 60 年／後 30 年）と月へ直接ジャンプ。‹ › や「今日」での移動も可能。月を切り替えると選択日もその月に追従
- 予定はカレンダー上でチェックでき、チェック後は自動更新
- **予定を別の日付セルにドラッグすると日程変更**（時刻はそのまま、日付だけ変更）
- データは**すべてのボード**の ToDo から取得し、繰り返し ToDo はルールに従って複数回に展開されます

**Token 使用量ボード**
- **データはローカルの opencode データベース**（既定 `~/.local/share/opencode/opencode.db`、設定でパス変更可）から取得。**完全にオフライン**、読み取り専用で開き、他人の DB には書き込みません
- 読むのは `session_message`（v2）1 テーブルのみ。旧 `message`（v1）は内容がすべて v2 に移行済みで公式も書き込まないため、コードでは完全に無視
- **範囲切り替えが速い**：大きな JSON は 1 行につき 1 回だけパース（複数パスの `json_extract`）、時間条件は最内 `WHERE` に押し下げ、1 本の SQL で合計・推移・モデル別を同時に算出。過去の日付は日単位でメモリにキャッシュし、「今日」だけ毎回再計算
- **自動更新間隔 5／15／30 秒**を選択可能。⟳ で手動更新もできます
- **集計範囲**：今日（時間単位）／直近 3 日／直近 7 日／直近 30 日（7 日以上は日単位に自動集約）
- 上部サマリー：総 Token、呼び出し回数、キャッシュ率。その下の行に入力／出力／推論／キャッシュ読取を分割表示
- **推移グラフ**：積み上げ棒（入力／出力／推論／キャッシュ読取／キャッシュ書込）＋折れ線（呼び出し回数）。**棒や折れ線の点をクリックするとその時間帯の明細を表示**。自動更新で開いている明細が消えることはありません
- **モデル別**：モデルごとの Token 合計、占有率、呼び出し回数と内訳
- 取得失敗はフッターに表示するだけでモーダルは出しません。オフライン時は直前のデータを保持します

**ポモドーロタイマー**
- トレイメニューの「ポモドーロタイマー」から開く独立した小ウィンドウ、既定で最前面
- 25 分集中＋5 分短休憩、**4 ポモドーロごとに 15 分の長休憩**（サイクル数は `PomodoroEngine` で設定可能）
- 円環の進捗と大きなカウントダウン。**集中と休憩で配色を変更**、円環は 30fps で補間
- 開始／一時停止／再開／リセット／スキップ。集中終了時はトレイ通知、休憩終了時は次の集中へ自動移行
- **今日の完了数を保存**、日付が変わると自動でリセット

**ToDo（表形式のインライン編集）**
- **「追加」ボタンもチェックボックスもありません**：リスト末尾に常設の下書き行「＋ ここに入力し、Enter で追加」
- **操作ボタンは行にマウスが入ったときだけ表示**（**行末の右端**に固定、タイトル領域を圧迫しません）：ToDo 行は `✓`（完了）と `✕`（削除）、完了行は `↺`（未完了に戻す）と `✕`
- **2 行目のバッジとタグ名はタイトルの左端に揃います**
- **どの行も直接編集可能**：タイトルをクリックで編集、Enter で確定して次の行へ、Tab や他の場所のクリックでも自動確定、Esc で取り消し
  - 空タイトルは拒否され、元の値に戻り、行内に「内容を入力してください」と表示
  - フォーカス中の行は強調され、入力欄に琥珀色の縁取りが付くので誤編集しません
- **ドラッグハンドル**（各行の左側の 3 点）：上下ドラッグで並べ替え、上のタグチップにドロップでそのタグを付与、「すべて／未分類」にドロップでタグ解除
- **余白をクリックすると編集終了**：入力欄以外のどこかをクリックすると、編集中の行を確定してフォーカスを外します
- **TODO / Done ビュー切り替え**：下部のセグメントボタン（`未完了 N` / `完了 N`）でワンクリック切り替え
  - ToDo ビューは未完了のみ、手動で並べ替えた順序を維持
  - Done ビューは完了のみを**完了時刻の降順**（最近の完了が上）で表示し、各行に完了時刻ラベルを付けます（今日 14:41／昨日 09:05／10月18日 20:11／2025年12月30日 08:00）
  - Done ビューでは下書き入力欄が無効化され、「追加したのに見えない」を防ぎます
- **期限（カウントダウン）**：右クリックで今日／明日／今週末／カスタムを設定。行に「あと N 日／今日が期限／N 日超過」を表示し、超過は赤字
- **リマインダー**：右クリックで 30 分後／1 時間後／今日 18:00／明日 9:00／カスタムを設定。時刻になると右下の小ウィンドウ＋トレイバルーンで通知し、「10 分後に再通知」も可能。20 秒間隔のポーリングで、すべてローカル
- **繰り返し ToDo（RFC 5545 RRULE）**：右クリックで毎日／平日毎日／毎週／2 週間ごと／毎月／毎月末日／毎年、またはカスタム RRULE（例 `FREQ=MONTHLY;BYDAY=2TU`）を入力
  - チェックしても消えず、**完了履歴を 1 件記録し、期限を次回に繰り越します**（リマインダー時刻も連動）
  - 行には 🔁 バッジと人が読める説明を表示
- **ドラッグ並べ替え**（添字ではなく「ある項目の前に移動」を使うため、タグで絞り込んだ状態でドラッグしてもズレません）
- 右クリックメニュー：完了状態の切り替え、タグの付け外し、期限設定、リマインダー設定、繰り返し設定、削除

**タグ**
- グローバルタグ。1 つの ToDo に複数付けられます。絞り込みチップは「すべて／未分類／各タグ」で件数付き
- タグの作成・名前変更・削除が可能。タグを削除しても ToDo 自体は影響を受けません

**グローバルホットキー**（他のウィンドウにフォーカスがあっても動作）
- `Ctrl+Alt+N` 新規 ToDo（既定の ToDo ボードを開き入力欄にフォーカス）
- `Ctrl+Alt+H` すべての付箋を表示／非表示
- `Ctrl+Alt+L` 現在のボードをロック／解除
- 登録に失敗した場合（他プログラムが使用中）は静かにスキップし、起動には影響しません

**モーション（一貫した即時フィードバック）**
- **ウィンドウ入場**：位置が確定してからフェードイン＋わずかに拡大（アニメーション対象は Window 自体ではなく中身。透過ウィンドウがアニメーション中にビットマップ化されて文字がぼやけるのを避けるため）
- **ボタン**：ホバーでハイライト層がフェードイン（色の切り替えではない）、押下時に 4% 縮んで戻る。`Primary` / `Ghost` / タイトルバーの丸ボタン / タグチップすべてに適用
- **チェックボックス**：チェック時に四角が 1.18 倍に拡大して戻り、チェックマークが 40% から 100% に伸びます（`BackEase`）。解除時は逆再生
- **スライダー**：つまみはホバーで 1.2 倍、ドラッグ中は 1.35 倍
- **ToDo 行**：ホバーで行末ボタンがフェードイン、`✓` で行がパルス、`✕` では行がフェードアウトしてから実際に削除、Enter で追加した行は上からスライドイン
- **タグチップ**：選択時は太字と配色変更、ホバーでハイライトのグラデーション
- **リストカード**（管理パネル）：ホバーで 1.2% 拡大
- **カレンダーのセル**：ホバーで 4% 拡大＋強調、日付クリック時に下の吉凶パネルがフェードイン
- **リマインダー**：下からスライドイン＋フェードインで見落としにくく
- **Token ボード**：取得中は更新アイコンが回転。初回読み込み時のみボタンが暗くなり、範囲切り替えではちらつきません
- **ポモドーロ**：進捗円環を 30fps で補間し、250ms ごとの飛びではなく流れるように動きます
- **OS 設定を尊重**：Windows の「ユーザー補助 → 視覚効果 → アニメーション効果」をオフにすると、すべてのモーションをスキップします（`Motion.Enabled` が `SystemParameters.ClientAreaAnimation` を参照）

**その他**
- 単一インスタンス（`Local\StickyTodo.SingleInstance`）
- Serilog のローテーションログ＋グローバル例外ハンドリング
- データベースの自動マイグレーション（`PRAGMA user_version`、v1→v4 実装済み）

## 4. データモデル

```sql
board(id, name, sort, is_default, kind, created_at,
      win_left, win_top, win_width, win_height)          -- kind: todo | memo | calendar | token
todo(id, board_id→board.id ON DELETE CASCADE, title, note,
     is_done, done_at, due_at, remind_at, reminded_at, recurrence,
     sort, created_at, updated_at)                        -- recurrence: RFC5545 RRULE
todo_completion(id, todo_id→todo.id, occurrence_at, completed_at)
tag(id, name UNIQUE COLLATE NOCASE, color, sort, created_at)
todo_tag(todo_id→todo.id, tag_id→tag.id, PRIMARY KEY(todo_id, tag_id))
note(id, board_id→board.id UNIQUE, content, created_at, updated_at)
setting(key PRIMARY KEY, value)
```

設計上のポイント：

- **時刻はすべて Unix 秒（INTEGER）で保存**し、読み出し時に `.ToLocalTime()` でローカル時刻に戻します（そうしないとリマインダー時刻がタイムゾーン分ずれます。実際に踏んで修正済みの不具合です）。`DateTimeOffset` はリポジトリ境界でのみ変換します。
- **論理外部キー＋カスケード削除**：各接続で `Foreign Keys=True` を有効化。ボードを削除すると ToDo も削除され、タグを削除すると関連も削除されます。
- **WAL モード**（`journal_mode=WAL`、`synchronous=NORMAL`）。複数ウィンドウの同時読み取りが安定します。
- **マイグレーションは `PRAGMA user_version` を増やす方式**で、`Initialize()` は冪等。`SchemaMigrationTests` が実際の v1 DB を自動アップグレードし、データが失われないことを検証します。
- リポジトリは短命な接続＋接続プールを使い、長命接続を保持しません。複数ウィンドウやバックグラウンドスレッドとの競合を避けるためです。

## 5. 完全ローカル（検証可能であり、スローガンではない）

- Token 使用量ボードが読むのは**ローカルの opencode SQLite データベース**で、ローカルファイルの読み取りです。同じく通信せず、何も送信しません。
- アカウント体系、クラウド同期、計測、バージョンチェックはありません。
- ホストは意図的に `Host.CreateDefaultBuilder()` ではなく `new HostBuilder()` を使っています。前者は `appsettings.json`／環境変数／コマンドライン設定を読みに行きますが、ここでは設定ソースをすべて無効化し、挙動はコードのみで決まります。
- 実行可能な保証：`tests/StickyTodo.Tests/NoNetworkTests.cs` が **Core と Infrastructure の参照アセンブリ一覧に** `System.Net.Http` / `System.Net.Sockets` / `System.Net.Requests` / `System.Net.WebClient` **が含まれないこと**を検証します。これらの層にネットワーク依存が戻された瞬間にテストが失敗します。

## 6. メンバーシップ戦略（重要）

リリース版は `PermanentFreeEntitlement` を登録しています：

```csharp
// src/StickyTodo.App/App.xaml.cs
services.AddSingleton<IEntitlementService, PermanentFreeEntitlement>();
```

`PermanentFreeEntitlement` はすべての上限が `int.MaxValue`、`IsPro = true`、`Tier = Lifetime` なので：

- UI 上のメンバーシップバッジ、権利判定、上限チェックの**ロジックはすべて残っており正常に動作**します（判定を削除したわけではありません）；
- ユーザー体験としては永久無料・機能制限なし；
- 将来課金する場合も `FreeTierEntitlement`（実装済み：ボード 2／タグ 3／繰り返しルール 5／ICS なし）に差し替えるか、「ローカルのライセンスファイルから段位を読む」実装を追加するだけで、**ビジネスロジックと UI コードは 1 行も変更不要**です。

上限チェックは `TodoService` の層にのみ置き、UI は `EntitlementLimitException` を表示するだけです。

## 8. 既知の制限

- タイトルバーのカスタムスキンはありません。付箋は自前描画のタイトルバーを使い、メイン画面と設定画面も自前描画です。ドラッグや吸着はこれに依存するため、変更時は操作感を考慮してください。
- 吸着はウィンドウ外枠で計算するため、DPI の異なるモニター間では近似値になります。
- タグ絞り込みは単一選択のチップです。2 つのタグを同時に絞り込む機能は未実装です。
- カレンダーは月表示のみです。繰り返しルールは「今回だけスキップ」「単回のみ編集」に未対応です（編集するとルール全体が変わります）。
- **休日・振替出勤のデータは手入力**です（2024〜2026 年を収録）。国務院は毎年 11 月頃に翌年の日程を公表するため、その際に `ChineseHolidays` へデータを追加する必要があります。範囲外の年は「週末は休み」という既定の判定のみになります。
- **二十四節気は汎用の日数計算式で求めている**ため、年によっては公式暦と 1 日ずれることがあります（式内の例外表で既知のずれは補正済み）。
- **吉凶の宜／忌は建除十二神から導いた汎用の項目**であり、日ごとの暦注ではありません。参考情報であり、日取り選定、神煞、時刻の吉凶は扱いません。
- **中国語以外の UI では旧暦の内容は中国語のまま表示されます**：これは意図的な割り切りです（上記「多言語」参照）。完全にローカライズしたい場合は `UiStrings` に訳を追加し、`Almanac` の項目もリソース化してください。
- **Token ボードは opencode のテーブル構造に依存**します（`session_message.data` 内の `tokens` / `model` フィールド）。opencode の改版でフィールドが変わると数値が 0 になるため、SQL の調整が必要です。DB が存在しない場合はフッターが設定画面での指定を促します。
- Token ボードで大きな範囲を**初回**に開くとき（直近 30 日は 100MB+ を読む）は 1 秒程度かかります。同じ範囲は 2 回目以降ミリ秒単位です。過去日付のキャッシュはメモリのみのため、再起動後の初回は再計算します。
- Token 統計は**メッセージ単位の使用量の累計**で、opencode 自身がセッション単位で累計する `session_v2.tokens_*` とは集計口径がわずかに異なる場合があります（メッセージ単位のほうが細かく、時間でバケット化しやすい）。
- 繰り返し ToDo の完了履歴は記録のみで未表示です（将来「今月何回完了したか」などの統計に使います）。
- UI 層に自動テストはなく、`--selftest` / `--recurrence-demo` / `--shot` など 12 の回帰モードで担保しています。

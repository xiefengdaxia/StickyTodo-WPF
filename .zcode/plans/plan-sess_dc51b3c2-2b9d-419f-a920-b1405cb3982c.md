# MCP 接入 + AI 自定义看板（两端全量）

## Context
给 StickyTodo 增加 MCP（Model Context Protocol）服务端：AI（ZCode/Claude 等）通过 MCP 工具创建/关闭看板、调用全部应用功能；同时新增「自定义看板」类型——UI 是 AI 编写的 HTML（WebView2 渲染），数据来自 AI 编写的采集脚本（Jint JS 沙盒定时抓取网站/服务器，回填到看板）。决策已确认：两端（WPF net8 + Avalonia net6/Win7）全量实现，Avalonia 用 NativeControlHost 嵌 WebView2；采集脚本用 JavaScript 沙盒。

约束（探索已确认）：
- `tests/NoNetworkTests` 禁止 Core/Infrastructure 引用网络程序集 → MCP 代码放**新项目 src/StickyTodo.Mcp**（多目标 net8.0;net6.0，引用 Core+Weather，包 Jint）。
- 现有 TODO 无事件推送，MCP 改数据后需主动刷新已打开的看板窗口（`BoardViewModel.LoadAsync()` 可复用）。
- BoardKind 新增 Custom 需同步 `BoardKinds.ToStorage/Parse/DisplayName` + 两栈 `WindowManager.OpenBoard` switch。
- 当前 SchemaVersion=7，升 8：board 加 custom_html/custom_script/custom_interval 三列。
- AppPaths 是令牌文件/WebView2 数据目录的落点。

## 1. Core / Infrastructure 改动
- `Entities/BoardKind.cs`：`Custom = 9`，常量 `"custom"`，ToStorage/Parse/DisplayName("自定义看板") 各加分支；IsToolBoard 保持 false。
- `Entities/Board.cs`：加 `string? CustomHtml / CustomScript / int? CustomIntervalSeconds`。
- `ITodoRepository` + `SqliteTodoRepository`：CurrentSchemaVersion=8，`SchemaV8`（3 个 ALTER TABLE ADD COLUMN）+ `if (version<8)`；GetBoards 映射新列；新增 `SaveCustomContent(boardId, html, script, intervalSeconds)`。
- `TodoService`：`SaveCustomBoard(...)`（校验存在且为 Custom），interval 夹取 15..86400。
- `AppSettingsService`：`McpEnabledKey="mcp.enabled"`(默认 false)、`McpPortKey="mcp.port"`(默认 52700，夹 1024..65535) 及属性。
- `Infrastructure/AppPaths.cs`：`McpTokenPath`、`WebView2DataDirectory`（DataDirectory 下 mcp.token / webview2 子目录）。

## 2. 新项目 src/StickyTodo.Mcp
csproj：net8.0;net6.0，引用 Core、Weather，NuGet Jint 3.x。

- **McpProtocolHandler.cs**：纯 JSON-RPC（System.Text.Json）。initialize（protocolVersion "2025-06-18"，capabilities.tools，serverInfo name/version）、notifications/initialized→202、ping、tools/list、tools/call（异常→isError 文本）、另兜 resources/prompts list 空结果。
- **McpHttpServer.cs**：TcpListener 只绑 127.0.0.1，手写最小 HTTP/1.1（无 HTTP.SYS ACL 风险）：解析请求行/头/Content-Length(≤4MB)、`Authorization: Bearer <token>` 校验（401）、POST /mcp 处理（通知→202 空体，请求→JSON 响应）、GET→405、端口被占自动 +1..+20 并暴露实际端口；Start/Stop 可在设置页实时开关。
- **McpToolRegistry.cs**：工具注册表（name/描述/inputSchema DSL/执行函数），依赖 TodoService、AppSettingsService、PomodoroEngine、WeatherService、ITokenStatsProvider、CollectorHost、IMcpUiHost。约 30 个工具：
  - 看板：list_boards / open_board / close_board / create_board(name, kind: todo|memo|calendar|token|custom) / rename_board / delete_board
  - 待办：list_todos / get_todo / add_todo(title, board_id?, due_at?, remind_at?, recurrence?) / update_todo(title?, note?, due_at?, remind_at?, recurrence?) / set_todo_done / delete_todo
  - 便签/标签：get_note / save_note / list_tags / set_todo_tags
  - 番茄钟：pomodoro_status / pomodoro_control(action: start|pause|reset|skip)
  - 数据：get_weather(city?) / get_token_stats(days: 0|3|7|30)
  - 系统：notify(title, message) / take_screenshot（GDI 全桌面截屏→PNG base64，两栈都提供）/ get_settings / set_setting(key,value 白名单：皮肤、语言、透明度、eye.* 等)
  - 自定义看板：create_custom_board(name, html?, script?, interval_seconds?) / update_custom_board / get_custom_board / push_custom_data(board_id, data)（AI 直接推数据，不走采集器）/ run_collector / get_collector_status
  - UI 类操作经 IMcpUiHost（RunOnUi/OpenBoard/CloseBoard/Notify/RefreshOpenBoards/CaptureScreenshot），两栈各自实现。
- **McpStdioBridge.cs**：`StickyTodo.exe --mcp` 时运行（在启动互斥量/Host 之前拦截）：逐行读 stdin JSON-RPC → POST 127.0.0.1:port/mcp（Bearer，令牌读 McpTokenPath）→ stdout 回写；应用未运行则尝试启动 exe 并轮询 12s；EOF 退出。
- **Collector/CollectorHost.cs**：后台 1s 节拍循环（每 30s 从 TodoService 重同步 custom 看板集合），到期即 Task.Run 执行：每脚本一次全新 Jint Engine（LimitMemory 8MB、TimeoutInterval 15s、MaxStatements 20 万），仅暴露 `http(url,{method,headers,body,timeout})`/`http_get(url)`（共享 HttpClient，响应体≤2MB）与 console.log（留日志尾）；约定脚本定义 `collect()` 同步返回可序列化对象。缓存 LastData/LastError/FetchedAt/日志，事件 `DataChanged(boardId)`；`RunNow(boardId)`、`PushData(boardId, json)`。
- **CustomBoardTemplate.cs**：默认 HTML 模板（监听 `window.chrome.webview` message 的 `{type:'data'|'error'}` 渲染 JSON，跟随系统深浅色）。

## 3. WPF 栈（src/StickyTodo.App）
- csproj：加项目引用 + Microsoft.Web.WebView2 包。
- App.xaml.cs：DI 注册 McpToolRegistry/CollectorHost/McpHttpServer；启动尾部 enabled 时 Start；OnExit Dispose；`--mcp` 早于互斥量拦截（放 App.Smoke.cs 附近）。
- `Services/McpUiHost.cs`：IMcpUiHost 实现（Dispatcher.Invoke、复用 `ScreenCaptureService.CaptureVirtualScreen` + PngBitmapEncoder）。
- WindowManager：OpenBoard 加 `BoardKind.Custom => new CustomBoardWindow(...)`；新增 `RefreshOpenBoardsAsync()`（新增小接口 IBoardDataRefresh，Board/Memo/Calendar/Token 窗口调各自 VM.LoadAsync）供 MCP 写操作后调用。
- `Views/CustomBoardWindow.xaml(.cs)` + `ViewModels/CustomBoardViewModel.cs`：工具窗样式（WindowGeometryMemory.Attach），WPF WebView2 控件（DefaultBackgroundColor=Transparent、NavigateToString ≤1MB、NewWindowRequested/Download 拦截），订阅 CollectorHost.DataChanged → PostWebMessageAsJson；运行时缺失或加载失败 → 显示数据 JSON 预览兜底。
- SettingsViewModel/SettingsWindow.xaml：新「MCP 接口」卡（启用开关、端口、令牌只读框+复制、实际地址状态、ZCode/Claude 接入配置示例可选中文本，改端口/令牌即时重启服务）。
- TrayService：加「MCP 接口」勾选 + 「复制接入配置」；ManagerViewModel/ManagerWindow：新建看板入口加「自定义看板」（空模板）。
- UiStrings：`mcp.*`/`settings.mcp*` 约 15 键 × 4 语言。

## 4. Avalonia 栈（src/StickyTodo.Avalonia，镜像 WPF 全部）
- csproj：项目引用（WebView2 包 Microsoft.Web.WebView2 亦引，SDK 支持 net6）。
- Program.cs：`--mcp` 在 Avalonia 启动前拦截；AppServices 加 CollectorHost/McpServer/McpUiHost + Dispose；App.axaml.cs 启动尾部 Start。
- `Services/ScreenCaptureService.cs`：从 WPF 复制 GDI 截屏（纯 GDI，无 UI 依赖）→ take_screenshot 两栈可用。
- `Services/WebView2Host.cs`：NativeControlHost 子类——CreateNativeControlCore 建子 HWND，异步 CreateCoreWebView2ControllerAsync(hwnd)（userDataFolder 用 AppPaths.WebView2DataDirectory），按物理像素同步 Bounds，暴露 Navigate/PostJson/销毁；运行时缺失→事件上抛由窗口走兜底 UI。（Win7 需 ≤Chromium109 的旧版 WebView2 运行时，设置页提示文案会写明。）
- CustomBoardWindow.axaml(.cs)+VM、设置卡、托盘、管理面板入口与 WPF 同构；UiStrings 在 Core 已共用。
